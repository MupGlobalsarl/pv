Installer sur Android (Chrome)

  1. Ouvrez ce lien dans Chrome. Si WhatsApp l'ouvre lui-même : menu ⋮ → « Ouvrir dans Chrome ».
  2. Touchez « Installer l'application » ci-dessus, ou menu ⋮ → « Installer l'application » / « Ajouter à l'écran d'accueil ».
  3. Confirmez Installer : l'icône MUPGLOBAL PV apparaît sur l'écran d'accueil.
  4. Ouvrez l'icône, copiez le code de l'appareil et envoyez-le à MUPGLOBAL SARL pour recevoir votre clé.

Pas d'icône ? Paramètres du téléphone → Applications → Chrome → Autorisations → activez « Raccourcis sur l'écran d'accueil », puis recommencez. Regardez aussi dans la liste de toutes les applications.

Installer sur iPhone / iPad (Safari)

  1. Ouvrez ce lien dans Safari (pas dans WhatsApp ni en navigation privée).
  2. Touchez le bouton Partager ⇧ en bas de l'écran (en haut sur iPad).
  3. Touchez « Sur l'écran d'accueil » (si absent : « Modifier les actions » en bas de la liste), puis Ajouter.
  4. Ouvrez l'application depuis l'icône MUPGLOBAL PV et demandez votre clé depuis l'icône : sur iPhone, l'icône a son propre code d'appareil.

iOS 16.4 ou plus récent : possible aussi depuis Chrome (bouton Partager ⇧ dans la barre d'adresse).
