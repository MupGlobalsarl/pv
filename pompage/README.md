# MUPGLOBAL Pompage – application de pompage solaire

Application mobile de **MUPGLOBAL SARL** (Lubumbashi, RD Congo) : dimensionnement d'une station de pompage solaire au fil du soleil, devis, plan d'affaires et livre de formation des techniciens. Fonctionne sans Internet après installation.
